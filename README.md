# Yuri Patrick — Portfólio

Portfólio de edição de vídeo e motion design de Yuri Patrick.

O site é estático, responsivo e usa capas locais para os vídeos. Os vídeos são reproduzidos pelo Google Drive, então precisam estar compartilhados para visualização.

- Reels e motion design
- Contato direto pelo WhatsApp e Instagram
- Feito com HTML, CSS e JavaScript
